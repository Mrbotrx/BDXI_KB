Reporting a Vulnerability

Please report security vulnerabilities privately through the GitHub Security Advisory feature.

Repository: https://github.com/Mrbotrx/BDXI_KB

Please include:

- Vulnerability description
- Steps to reproduce
- Affected file or feature
- Proof of concept, if available

Please do not report security vulnerabilities through public Issues or Pull Requests.

Thank you for helping keep BDXI_KB IPTV secure.
